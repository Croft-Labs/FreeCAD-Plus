# Design Layers acceptance

Run `TestDesignLayers` in the Plus GUI runtime. The source overlay exercises real
native document properties, transactions, Coin scene graphs and geometry. It does
not certify rebuilt native Selection gates or a packaged owner build.

The fixture covers Base and origin protection, active creation, native Body
operations versus nested sketches, Plus result/consumption chains, deduplicated
occurrence selections, multi-object movement, deletion without geometry changes,
active fallback, undo/redo, old assignments and FCStd/cadprt save/reopen. Visibility
checks use native Coin bounding boxes, preserve individual Visibility values and
keep Body Group traversal for independently layered sketches. Toolbar/task checks
exercise actual menus, row activation and eye controls.

Prompt 10 must also verify filtered viewport clicks/preselection/box selection with
hidden layers, external/repeated component render contexts, Body Through/Tip modes,
late geometry providers and theme/high-DPI toolbar lifecycle in the packaged build.
No source-overlay result alone establishes physical owner acceptance.
