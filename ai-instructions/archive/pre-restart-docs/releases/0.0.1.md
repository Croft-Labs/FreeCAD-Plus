# FreeCAD Plus 0.0.1 — Pre-Release

First Windows x64 preview of FreeCAD Plus, based on FreeCAD's development branch.

Download and run `FreeCAD-Plus-0.0.1-Windows-x64-Setup.exe`. Installation is per user.
Launch **FreeCAD Plus** from its Start-menu folder. It uses separate preferences
and does not replace upstream FreeCAD or change file associations. Uninstallation
retains user preferences and documents. The installer is unsigned.

Installer size: 360,754,930 bytes. SHA256:
`c969fb92aea4cbd4da400d78dfb18d3674de16ebb68d9a4432f3f1bcc1b33dd8`.

Included fork workflows:

- Unified Add/Subtract Extrude with profile selection in the task pane and start offsets.
- Linear/Circular Pattern task workflow and angular start offsets for Revolution/Groove.
- Associative Trim Body and Isocline Curves.
- STL CAM Parallel/Waterline, holding tabs, indexed-setup work, and recent stale-path safeguards.

Included workbenches: Part, Part Design, Sketcher, CAM, Draft, Mesh, Material,
Spreadsheet and TechDraw, with Import, MeshPart and Measure support. This is the
focused fork build, not the complete upstream workbench distribution; Assembly,
FEM, BIM and Addon Manager are not included.

The distribution version is **0.0.1**. About continues to report the upstream-derived
**26.3.0 development** engine version. Application source commit:
`2df76790b4ebcd94d77ccbbc3fdac0d6016728b8`.
The release tag also includes the installer scripts and release documentation.

Validation: 120 modeling, task-pane and CAM regression checks passed against the
staged runtime. A stale embedded revision was then refreshed; launcher smoke passed
with the correct revision and verified separate settings, native imports and
save/reopen. The actual installer passed installation, 11 key file-hash checks,
installed launch/save/reopen, shortcut registration, and uninstallation with unrelated
file preservation. Evidence and artifact identity are recorded in the roadmap.

This pre-release does not establish machine-cutting safety or full GUI acceptance.
Review and simulate generated CNC paths before use. Save copies of important models.
The planned `.cadprt` format and unified NX-style production history are not part
of this release. Current files remain `.FCStd`; fork-only features may require
FreeCAD Plus to recompute correctly in their original editable form.

FreeCAD and dependency licenses/attribution are retained in the installed files.
Corresponding fork source and packaging scripts are available at this release tag.
