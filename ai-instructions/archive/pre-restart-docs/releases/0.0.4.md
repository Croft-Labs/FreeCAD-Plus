FreeCAD Plus 0.0.4 is an experimental Windows x64 pre-release.

Changes since 0.0.1:
- CAM dressups reject stale dependencies and clear failed machining output; improved holding-tag, boundary, mirror, axis-map, Z-correction and Dogbone validation/recovery.
- Plunge Milling adds explicit clearance/retract moves, drilling-cycle feed/cancellation and invalid-cycle validation. Bounded LinuxCNC/Grbl export and FCStd reopen checks are included.
- Holding Tab and Indexed Setup commands now correctly open their creation task panes and preserve unrelated transactions.
- Trim Body and Isocline task workflows have improved transaction, selection and dependency handling.

This installer includes Part, Part Design, Sketcher, Mesh, Mesh Part, CAM, Draft, TechDraw, Spreadsheet, Import, Material and Measure in the existing focused build configuration. It is not an all-workbench upstream distribution.

Install per user and launch FreeCAD Plus from the Start menu. Preferences are separate from upstream FreeCAD; file associations are unchanged. The installer is unsigned. The retained upstream-derived engine version may appear as 26.3.0 in About.

The planned .cadprt format, production NX-like part history and experimental parameter-editor prototypes are not included. Existing FCStd documents remain the working format; fork-specific features may require FreeCAD Plus to recompute. Back up important documents before using this pre-release.

Automated validation does not establish controller/physical-machine safety or full interactive acceptance. Other controller/cycle combinations and broader roadmap acceptance remain open.
