FreeCAD Plus 0.0.2 is an experimental Windows x64 pre-release, published on request after 0.0.4.

This is a new 0.0.2 installer for the same tested application source as 0.0.4, not a rollback to an earlier feature set. It includes the unified Extrude and Pattern workflows, angular Revolve offsets, Trim Body, Isocline Curves, STL CAM and holding-tab/indexed-setup changes, plus the recent CAM validation fixes.

Included workbenches/modules: Part, Part Design, Sketcher, Mesh, Mesh Part, CAM, Draft, TechDraw, Spreadsheet, Import, Material and Measure in the focused build configuration. This is not an all-workbench upstream distribution.

Install per user and launch FreeCAD Plus from the Start menu. The installer uses its own 0.0.2 installation directory and registration. FreeCAD Plus releases share their fork-specific preferences, separate from upstream FreeCAD. File associations are unchanged. The installer is unsigned; the retained engine version may appear as 26.3.0 in About.

The planned .cadprt format, production NX-like part history and experimental parameter-editor prototypes are not included. FCStd remains the working format; fork-specific features may require FreeCAD Plus to recompute. Back up important documents before using this pre-release.
