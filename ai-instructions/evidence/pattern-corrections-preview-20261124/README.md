## Requested workflow

- Fit Pattern fields to narrow task docks. Direction method and reference occupy
  separate rows; numeric fields shrink with the panel, preserve six-decimal units,
  and keep Reverse accessible. Long labels wrap; natural-height sections scroll vertically.
- After geometry is selected, preview each complete active direction independently.
  A complete X direction appears while Y is incomplete; adding Y yields the full grid.
  Apply the same rule to angular/radial combinations. A circular preview needs a center.
  Keep Apply unavailable until the entire selected operation is valid; show partial
  preview guidance. Invalid edits must not leave a stale preview.
- Preview construction spacing lines and angular arcs when Create spacing constraints
  is on and Hide spacing chain is off. Hiding removes helpers from preview without
  changing pending pattern geometry. Preview must not create persistent geometry,
  constraints, hidden-state changes or Undo entries.
- Keep the source's size driver. Copied circles/arcs share native Equal radius
  relationships; copied line lengths share Equal relationships. Do not replicate
  driving size measurements onto every copy. Preserve source freedom, source expressions,
  reference measurements and distinct pitch drivers. Native Equal semantics differ
  by curve type: equal arc radius alone does not fix sweep; preserve the separate
  angular placement/shape relationships without introducing repeated size drivers.
- In task panels with a completion Done/Apply pair, Done goes left and Apply right.
  Done applies valid pending input and closes the tool while staying in sketch edit.
  Apply applies and clears geometry/reference selections for another operation,
  preserving numeric/mode/options settings. Empty Done closes without applying twice.
  Incomplete/invalid pending input stays open with guidance; failures retain input.
  Escape/Cancel discards pending preview without applying. Existing applied results remain.

Audit found these completion pairs in Sketch Pattern and Mirror. Other task panels
use OK/Cancel/Apply or a Done button to end a selection step; those are different
workflows and are preserved. Retain axes, sketch header buttons, picking gestures,
counts including original, independent/symmetric extents, pitch/total, units,
construction status, source geometry, native transactions and saved-file identities.
